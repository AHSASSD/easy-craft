# 显示与音画自动保存、插件侧栏

声音与画面属于实例 options.txt 配置；不属于单个世界的 level.dat。实例设置保留这个作用范围，压缩重复标题、说明和手动保存按钮。启动窗口和音画修改停止 500ms 后自动保存；切换页面时等待保存完成，正常路径不弹“尚未保存”确认。保存失败保留编辑值，显示错误并提供重试，不静默离开。运行／任务互斥、文件版本核对、原生配置备份继续有效。世界规则、Java／内存等其他编辑界面仍保持各自的保存流程。

插件侧栏按用户澄清采用游戏库条目形式：顶部“我的插件 + 数量”、添加按钮、搜索框、独立滚动列表；条目包含图标、名称和类型／来源／版本。选中高亮，右侧显示详情，导入后滚动到选中条目。底部为本地导入、发现入口和固定账号区。

本地导入当前支持声明式布局／主题 JSON 插件，不执行外部脚本。示例：`docs/plugins/compact.ecplugin.json`。通过加号或底部按钮选择文件，校验后保存安装记录；点击“应用插件”更新布局或主题配置。安装记录随应用浏览器配置持久化，重启后保留。移除记录不会撤销已应用的外观偏好。

格式：`schemaVersion: 1`，自定义 `id`、`name`、三段数字 `version`、可选 `description`、`type` 为 `layout` 或 `theme`。布局 settings 仅允许 `layout: default|compact`、`sidebarWidth: 240..420`；主题仅允许 `theme: slate|grass`、六位十六进制 `accentColor`。文件最多 128 KiB，本地最多 50 个；重复 ID、官方 ID、未知字段及不兼容配置拒绝导入。社区商店、任意 JS/ZIP 功能插件运行时尚未实现。

验证：类型检查、ESLint、99 项前端测试、14 项既有 E2E、桌面构建通过。新增测试覆盖合并连续修改、切页补完保存、失败保留与阻止导航、插件格式及拒绝非法配置。实际 Tauri / WebView2 使用隔离合成存档验证音量调整自动写入、立即切页不弹确认且音乐音量仍保存；导入示例插件、搜索选择、应用紧凑布局、刷新后安装记录保留。没有修改用户的存档或账号。

桌面流程脚本：`scripts/verify-world-resource-ui.mjs`。截图／记录在 `output/playwright/world-resource-ui/`，最新成功目录记录于 `output/autosave-native.log`。运行产物：`src-tauri/target/debug/easy-craft.exe`。
