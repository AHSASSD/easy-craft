# 扩展侧栏：工具优先的单组折叠布局

按确认的界面方案实现，未新增或更改插件包格式、运行时、生效规则、权限或依赖接口。

- 固定顺序为“我的工具、实例扩展、界面外观”；新打开应用时默认展开我的工具。
- 点击标题只切换展开组，不切换右侧页面。每次最多展开一组；再次点击当前标题可收起。切换分类不清空当前选择，离开扩展页再返回时保留本次会话的展开组和选择。
- 高度与轻微淡入采用约 200ms 过渡；系统减少动画设置及启动器减少动画偏好均禁用过渡。收起内容使用 inert 与 aria-hidden，不能被误聚焦。
- 分类标题支持 Enter／Space，方向键、Home、End 可在三个标题间移动焦点。
- 左侧搜索匹配现有本地包，搜索或导入成功时展开界面外观；不伪造独立工具或实例扩展。现有支持范围仍为本地布局／主题 JSON 包。
- 插件下载和本地导入固定在侧栏底部，账号区保持底部位置。下载入口明确显示目录尚未接入。

当前还没有可执行的独立工具或实例扩展接口，因此这两组显示真实空状态。后续接口与工具内部工作区的生命周期另行确认，本轮没有实现第三方工具执行器。

验证：类型检查、ESLint、相关格式检查通过；99 项前端单元测试、14 项 E2E 通过。E2E 覆盖默认展开、单组切换、折叠后保留右侧详情、导入后的组归属与展开、刷新默认状态和现有配置应用。

实际 Tauri / WebView2 在隔离目录中验证默认工具组、折叠切换、导入布局包、右侧选择保留，以及 1120×720／900×600 逻辑窗口。截图和记录位于 `output/playwright/world-resource-ui/`，最新成功目录见 `output/extension-accordion-native.log`。

桌面验证时用户旧窗口仍在运行，额外构建了 `src-tauri/target/debug/easy-craft-ui-preview.exe`，没有结束或替换用户进程。预览构建的临时源码副本路径记录在 `output/extension-accordion-build-source.txt`，使用同一份已构建前端资源与项目依赖缓存；未复制账号或游戏数据。

后续用户窗口已关闭时，再通过标准构建脚本更新 `src-tauri/target/debug/easy-craft.exe`；结果见 `output/extension-accordion-build.log`。
