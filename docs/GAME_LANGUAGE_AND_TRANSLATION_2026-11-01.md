# 游戏语言与汉化资源包

后续更新：“获取汉化资源”已改为在启动器内自动匹配、下载、导入并启用；最新实现和边界见 [自动汉化记录](AUTOMATIC_TRANSLATION_2026-11-01.md)。下文保留首轮语言及手动导入实现记录。

## 本轮实现

- 实例设置 → 显示与音画加入“语言与汉化”。提供常用语言选择，已有非列表语言仍正确显示；语言修改自动保存，保留现有音量、画面、资源包列表和其他未知配置，并接入原有备份与恢复差异预览。
- 新安装的原版、Fabric、Forge/NeoForge 和整合包实例默认简体中文。整合包完成文件准备后，只调整新实例的 `lang`，其他包内配置保留；写入进入安装事务清单，提交校验与取消回滚仍有效。导入/引用的既有实例不批量改写语言。
- Minecraft 1.1–1.10 的区域代码使用大写，例如 `zh_CN`；1.11 及后续使用 `zh_cn`。保存命令在后端按实际实例版本转换，客户端不能借语言字段注入其他配置行。
- “导入汉化资源包”打开系统 ZIP 选择器；也支持文件输入与拖入卡片。复用现有资源包导入、路径/包格式检查、文件占用保护和同名不覆盖逻辑。取消不报错、不写入；错误显示实际原因。
- 资源包写入当前实例实际游戏目录的 `resourcepacks`，不会作为 Mod 写入 `mods`。导入后由玩家在游戏内启用并调整优先级，保留已有 `resourcePacks` 设置。
- “获取汉化资源”通过固定的系统浏览器入口打开 <https://cfpa.site/>，不接受任意传入 URL。不新增自动汉化 Mod，不默认覆盖任务、脚本、配置，不声称所有内容均已翻译。

## 参考与来源核对

- 本机 HMCL：`HMCL/HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/game/HMCLGameLauncher.java` 中首次启动生成 options 的逻辑明确说明不同年代语言代码大小写。参考这一兼容行为，代码自行实现。
- 本机 PCL 的 `PCLCS/Resource/WikiEntries.txt` 包含自动汉化更新等项目索引。项目名称索引不等于启动器从 MC 百科下载完整汉化资源，本轮未据此推断下载接口。
- [CFPA 项目说明](https://github.com/CFPAOrg/Minecraft-Mod-Language-Package)说明手动资源包和自动汉化更新 Mod 是两种使用方式；[官网](https://cfpa.site/)有对应游戏版本资源包入口。MC 百科可作为介绍和索引，具体资源仍由项目来源提供。没有接入不明镜像或复制第三方翻译文件。

## 边界

当前手动安装支持标准资源包 ZIP。需要覆盖任务书、脚本、配置或安装额外 Mod 的整合包汉化补丁须按作者说明处理；没有实现通用补丁覆盖器、自动下载更新或完整游戏语言目录枚举。现有其他语言值会保留，列表外语言可继续在游戏内选择。
