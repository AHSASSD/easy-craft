## 2026-10-25：本地 MRPACK 事务安装（增量 4）

- ZIP/MRPACK 检查接入受支持的安装计划：原版/Fabric 依赖、客户端条件、可选文件选择、大小与全部目标路径预览。原生端保存固定令牌与只读归档快照；安装仅接受令牌、实例显示名称及计划内可选项，不接受前端任意路径或 URL。普通 ZIP 只有根目录含有效 modrinth.index.json 才可进入该流程；CurseForge ZIP 仍仅识别。
- 客户端跳过不支持的文件与 server-overrides；通用 overrides 后应用 client-overrides。拒绝大小写/文件与目录冲突、路径穿越、保留的启动器记录/世界锁文件、不支持的加载器和来源。单归档 512 MiB、展开/计划 1 GiB、10000 文件、200 可选项有明确边界。
- 复用原版/Fabric 下载、缓存、取消及哈希校验；逐文件检查 SHA-1/SHA-512。以全新 UUID 创建尚未注册的实例目录，校验完成后原子更新 instances.json 才加入游戏库，不依赖非空目录整体重命名。提交前核对实例清单修订、目录身份和全部文件；来源记录在 game/.easycraft-pack.json。
