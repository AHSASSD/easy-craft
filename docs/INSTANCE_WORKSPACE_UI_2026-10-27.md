# 实例子页面 UI 重构（2026-10-27）

本轮沿用现有石墨灰、青绿强调与局部 Minecraft 地景，浅色主题使用同一套结构。修改范围为实例的模组、资源与光影、存档、截图、实例设置；没有修改 Minecraft 启动与导入后端。

## 页面变化

- 子页面使用紧凑实例页头，保留版本、加载器、账号、启动和启动检查。实例标签及内容筛选栏在滚动时保持可达。
- 模组：标题显示实际文件数与当前实例；搜索、启用状态和排序集中在工具栏。文件以紧凑行展示，识别出的可编辑模组显示版本标签；未知文件明确只读。导入继续使用既有安装预检与确认流程。
- 资源与光影：资源包和光影包在工具栏切换，共用搜索、排序、目录和导入入口。文件信息来自实际目录。
- 截图：使用自适应画廊，延迟加载缩略图；点击打开原图预览，支持 Esc 关闭。无法预览时说明状态，不伪造缩略图。
- 存档：左侧可搜索世界列表，右侧编辑选中世界。摘要显示实际模式、难度和规则数量；数据包、游戏规则和备份按需展开。切换世界时先清除旧编辑器，读取完成后再显示新世界；未保存修改仍受导航保护。
- 实例设置：拆为“显示与音画”“运行环境”“目录与隔离”。普通设置优先呈现，窗口行为说明、内存维护等高级内容折叠。目录作用范围明确区分独立和共享。
- 世界页只读取世界数据，音画页只读取 options，避免跨页面读取无关配置。

保留原有游戏运行期间的修改限制、游戏关闭确认、备份与版本校验、未保存提示、本地文件选择及安装预检。此轮没有增加虚构的诊断、修复或社区插件能力。

## 验证

- 类型检查、前端构建与 Windows 桌面构建通过。
- Vitest：9 个文件、85 项测试通过；新增世界页读取范围与切换时清空旧编辑器的回归验证。
- Playwright 既有浏览器流程：14 项通过。
- ESLint、Prettier 与 diff 空白检查通过。
- 使用构建后的真实桌面 EXE，通过 CDP 操作隔离测试目录：验证模组筛选、实际文件启停、资源与光影切换、6 张截图的延迟加载和原图预览、世界选择与规则搜索、实例设置分组及未保存导航保护。
- 检查普通 1120×720 窗口、800×540 最小窗口与 125% UI 缩放；五个页面无横向溢出。覆盖深浅主题、长名称、空目录状态与键盘关闭预览。

测试数据为明确标注的隔离 UI 夹具：惰性模组元数据 JAR、资源 ZIP、有效世界元数据样本，以及此前真实游戏截图的副本。它们用于验证桌面交互与文件操作，不代表这些夹具可启动为 Minecraft 实例。本轮没有启动游戏、登录账号或改写个人游戏目录。
