# 整合包默认补汉化与实例 Java

## 最终界面

汉化卡片两个按钮统一为 40px 高，移除主按钮默认 margin 导致的错位。Java 卡片按用户追加反馈简化为一个选择方式下拉框、一个路径输入框及一个“选择 java.exe”按钮，移除检测、保存和放弃按钮。选择器提供自动匹配所需主版本、指定 Java、从版本目录选取三种入口。选文件直接检测并保存；手动输入在结束编辑或导航时保存，失败保留原设置和输入。

## 默认汉化

- `settings.autoTranslatePacks` 默认 true，旧配置自动采用默认值。语言设置中的“新整合包缺少汉化时自动补充”是全局的新安装偏好，可随时关闭，不会因此移除已安装汉化。单次“自动安装汉化”及手动 ZIP 导入继续可用。
- 整合包发布到游戏库后，检查实际 resourcepacks 下 ZIP 的中文语言资源，以及已启用的已识别自动汉化 Mod。已有汉化时保留原文件与启用配置，不重复下载。仅启用 JAR 参与检查，不把任意 Mod 自带中文当成整合汉化包。
- 缺少汉化时复用已有 CFPA 匹配、下载、校验、备份和启用流程。阶段及结果进入原安装任务。汉化源无匹配、损坏或网络不可用时，已成功提交的整合包保留成功，不回滚整合包；日志明确说明补汉化未完成及原因。
- 取消补汉化不会删除已完成的游戏安装。原有 CFPA 支持范围、版本/格式验证与专用任务补丁限制继续适用。

## Java

- 复用系统文件选择器，仅由用户选定的实际 `java.exe` 接续现有 `-version` 探测。取消不保存。实际路径与检测到的主版本保存为当前实例的 `launch.javaPath` / `launch.javaVersion`；后端重新探测核对，拒绝不符合实例所需版本或 64 位架构的运行时，保留旧配置。
- “从版本文件夹选取”检查该实例的 `java/bin`、`jre/bin`、`runtime/bin`、`bin` 四个固定位置，不递归搜索或执行无关程序。选定后保存具体路径；没有找到则提示并保留原值。
- 自动模式清除路径覆盖，普通自建实例和导入实例现在均复用有界的本机兼容 Java 匹配流程，优先兼容的全局配置。内存、隔离等其他覆盖继续保留。
- 没有加入后台下载 Java、任意主版本强制启动或无界全盘扫描。
