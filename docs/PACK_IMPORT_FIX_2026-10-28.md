# 本地整合包导入修复与界面调整

## 原因与修复

截图中的 `386143 / 3404975` 在 CurseForge 公开文件接口返回空元数据，但官方 CDN 仍保留原文件。上次仅在独立测试库补录恢复信息，未随程序提供，因此用户的正常数据目录依然报错。

已将这个精确历史文件的恢复记录内置到安装器：绑定项目 386143、文件 3404975、`lootbags-2.5.8.7.jar`、302653 字节与 SHA-1 `762294ef3baf7a09d9d875e6218895fa51b89d43`。接口失效时从官方 CDN 读取同一文件并核对，不换版本、不跳过必需文件。未知的失效文件仍会停止安装并明确报告；这不是所有下架文件都能自动恢复的保证。

正常在线资源继续核对平台项目与文件归属，并固定下载缓存的本地 SHA-512。历史恢复记录的 SHA-1 是维护者核验后的兼容性数据，不冒充当前接口提供的发布者签名。

## 导入界面

预览首屏展示包名、Minecraft/加载器/整合包版本、在线资源数、覆盖内容大小、独立实例方式、实例名称和实际游戏库路径。文件列表、长路径与检查说明移入折叠区；支持范围仍可查看。

本地选择与拖入共用流程。取消更换文件保留已有预览；点击开始安装后关闭预览并打开任务进度。命名超过宿主 60 字符限制时不可提交。使用现有组件、图标和主题变量，没有新增依赖。

## 验证与清理

1. 新增真实网络回归测试 `retired_curse_file_recovers_without_user_receipt`：修复前复现截图中的原错误；修复后在随机空目录、无 `pack-recovery` 的情况下成功下载并核对原文件 SHA-1。
2. 自动回归覆盖已知恢复记录的精确 ID 绑定、未知 ID 不猜测、损坏本地记录拒绝；前端覆盖取消更换文件保留预览、确认后启动回调及冻结的安装选择。
3. `scripts/verify-mercury-pack.mjs` 改用全新数据目录 `.native/mercury-reinstall`，通过真实系统文件选择器选中原 ZIP 的工作副本，点击实际界面的安装按钮。测试不手动写恢复记录、不预填游戏和 Mod 缓存。原 ZIP 安装前后逐字节比较。
4. 桌面截图检查 1120×720 和 900×600 窗口，主要操作可达，详情可折叠。系统文件选择器取消也已实测。
