# Easy Craft：PCL 与 HMCL 界面参考调研

调研日期：2026-10-23。本文区分「源码事实」与「Easy Craft 设计建议」；建议不代表 Easy Craft 已经实现相应功能。

## 取样范围与可信边界

- **PCL 本地样本**：`PCL-2.99.0.0`，源码 `VersionBaseName` 为 `2.99.0.0`，并分别定义正式版、快照版版本代码。[版本声明](<E:/PCL2 code comparison/PCL-2.99.0.0/Plain Craft Launcher 2/Modules/Base/ModBase.vb:9>)。本文不把本地样本说成当前公开发行版，也未运行 PCL 桌面程序。
- **HMCL 本地样本**：`HMCL/HMCL-main`，根构建文件的 `version = "3.0"` 只证明这个源码包的构建配置，不足以证明某个当前稳定发行号。[构建配置](<E:/PCL2 code comparison/HMCL/HMCL-main/build.gradle.kts:11>)。本文导航细节均依据该本地样本，未运行 HMCL 桌面程序。
- **在线首方核验**：[HMCL 官方仓库](https://github.com/HMCL-dev/HMCL) 指向 [HMCL 官网](https://hmcl.huangyuhui.net/)，官网提供其文档链接。官网介绍了自动安装与个性化配色、背景；后台调研时文档站曾超时，随后主任务成功读取 [官方界面说明](https://docs.hmcl.net/launcher/gui-features.html)，确认其账户/游戏分组及全局游戏、Java、外观、下载等设置分类；下表的精确交互仍优先依据本地源码。在线 `main` 可以变化，不能据此认定本地源码与线上发行包完全一致。
- 本调研学习信息组织、操作反馈，不复制他人品牌、图形资源或整套源代码。下文引用代码是为了定位设计证据；如之后实际复用代码，须另外核对对应项目许可。

## 不应照搬的部分

1. **不要把参考项目全部功能当作本轮清单。** HMCL 本地根页有独立附加功能入口、实例页有投影与大量维护动作（[根导航](<E:/PCL2 code comparison/HMCL/HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/ui/main/RootPage.java:167>)、[维护菜单](<E:/PCL2 code comparison/HMCL/HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/ui/instances/GameInstancePage.java:381>)）。Easy Craft 当前只需要用户定义的三个入口，以及已有功能的清晰归属。
2. **不要照搬导航所在位置。** HMCL 根页将账户置顶（[账户项](<E:/PCL2 code comparison/HMCL/HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/ui/main/RootPage.java:113>)），用户明确要左下角账户。应借鉴交互关系，位置服从用户手稿。
3. **不要把右键当唯一入口。** HMCL 具有右键、滚轮切换等增强交互（[实例切换](<E:/PCL2 code comparison/HMCL/HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/ui/main/RootPage.java:129>)）。Easy Craft 可以保留这些捷径，但必须有同等可见按钮和键盘入口；滚动版本列表不应意外更改待启动实例。
4. **不要照抄密集监控指标。** PCL 剩余线程数在技术排查时有意义（[进度字段](<E:/PCL2 code comparison/PCL-2.99.0.0/Plain Craft Launcher 2/Pages/PageSpeedLeft.xaml:57>)）。Easy Craft 默认任务条只保留阶段、进度、速度，细节放展开区。
5. **不要照搬样机假数据。** 用户第二张图中的 Mod 数量、截图、磁盘占用、启动次数是视觉参考。本调研没有证明 Easy Craft 已具备其数据源；必须从本机真实实例取得后才能展示。
6. **不要将设置作用域隐去。** HMCL 源码分别使用 `GameSettings.Preset` 与 `GameSettings.Instance`（[全局设置](<E:/PCL2 code comparison/HMCL/HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/ui/main/LauncherSettingsPage.java:41>)、[实例设置](<E:/PCL2 code comparison/HMCL/HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/ui/instances/GameInstancePage.java:57>)）。Easy Craft 应在表单标题标注「全局默认」「仅此实例」「仅此世界」，并清楚说明继承关系；不能让用户误以为改变一个世界的难度会改变所有实例。

## 对后续方案的直接结论

以下为研究后的设计判断，而非参考项目的既有行为：

- 采用用户手稿的 **三入口 + 动态左栏 + 右侧详情**，账户常驻左下角，任务反馈保持全局可见。
- 方块入口建议显示名称「游戏库」，其左栏实际是已安装实例；「存档」留给实例右侧的世界管理。这样保留手稿图标，也避免用存档称呼游戏版本。
- 设置入口的左栏显示设置分类；下载入口的左栏显示资源类别，右侧由搜索、筛选、结果、详情与安装确认形成完整流程。
- 可拖动分隔线只改变两栏宽度，不能改变导航含义。记住每个入口上次选中的对象与滚动位置；全局切换不终止下载或游戏。
- 界面重构先连接已有真实能力，再接新资源服务与内容管理；未接通的类别写入规划，不宣称可搜索、可安装。

核验限制：本次只做首方网页与本地源码调研，没有对 PCL/HMCL 发行包进行现场交互测试；本地源码目录名和构建配置不用于推断最新发行号。
