# V0.2 实施范围

保持现有 UI 风格，仅增加原版启动工作区，后续视觉调整不改变 NativeService 契约。

1. 工具链：Rust、MSVC/SDK、Java 放在工作区 build-tools/easycraft，使用当前进程环境，不改全局 PATH。普通用户环境采用官方包解压，不安装完整 Visual Studio。
2. 原生宿主：限定的 Tauri 命令，独立 data 目录，设置/实例 JSON 与 Windows DPAPI 加密账户分离。
3. 原版：官方版本清单、资源/库 SHA-1 校验、受限来源、临时文件与续传、独立游戏目录、Java 版本/架构检测、参数构造和实际进程日志。
4. 正版登录：自有应用 Client ID，设备码授权、Xbox/XSTS/Minecraft 交换、刷新令牌安全保存。没有已获准 Client ID 或本人授权不能声称登录和游戏端到端验收。
5. 测试：Rust 安全与参数测试、真实公开元数据与下载集成检查、前端回归、Windows 原生编译与可执行文件。

当前以 Windows x64 和现代原版 arguments 元数据为边界。旧式 minecraftArguments、继承版本、第三方加载器和自动 Java 安装 UI 留待后续；为开发与验证提供工作区 Java 21，用户可以选择其他匹配版本 Java。

保留 V0.1 演示实例与流程，真实实例单独存储，避免把样例状态转换成已安装状态。
