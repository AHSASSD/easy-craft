## 安全与回归覆盖

路径越界、Windows 保留设备名、非官方下载来源、SHA-1 内容/长度、Range 续传响应、平台规则、含空格参数、Java 属性解析、Windows DPAPI 加解密/损坏检测、日志截断/脱敏、无账户启动拒绝、原子保存、只提取 DLL 的受限归档处理。

依赖检查发现 ZIP 提取相关安全修复，已将直接依赖升级到 zip 9.0.5；仍使用自有目标路径检查与链接拒绝，不调用通用 extract 将归档直接铺入游戏目录。参考 [RustSec RUSTSEC-2026-0369](https://rustsec.org/advisories/RUSTSEC-2026-0369.html)。

## 尚不能声称已通过

- 尚未收到 Easy Craft 自有 Client ID，也没有使用本人正版账户完成设备授权、令牌刷新和真正进入 Minecraft 的端到端验收。
- 没有使用其他启动器的 Client ID、读取其凭据、注入离线/假令牌或把构造参数成功描述成游戏启动成功。
- 其他游戏版本、旧式参数、加载器、整合包安装与干净 Windows 机器安装尚未验收。
- 原生拖动区域、最小化、不同 DPI 和安装后升级/卸载仍需进一步人工验收；自动检查覆盖可见控件、最大化还原与关闭。
