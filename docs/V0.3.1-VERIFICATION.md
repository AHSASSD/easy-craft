# V0.3.1 验证与边界

2026-10-23，本轮新增真实实例工作区、皮肤头像和启动前世界配置。原版/Fabric 下载、账户和内存功能继续使用已有 Rust 服务。

## 实现

- 首页展示真实实例和启动身份，使用原创方块景观 SVG，保留主题、本地背景与栏宽设置。演示数据仅出现在 `/?demo=1`。
- Rust 有界遍历 GZip/NBT，记录已有字段的字节位置，只替换选定字段；未知标签不反序列化重建。文件及解压后上限均为 16 MB，限制深度、节点与数组长度。
- 世界难度/锁定、默认游戏模式、命令权限、DayTime、天气与已有 GameRules。时间以十进制字符串传输，避免 JavaScript 超过 2^53 的整数精度损失。
- 布尔规则显示开关，i32 规则显示整数输入，其他文本只读；不添加不存在的规则。常见规则提供中文名称，其他规则保留原名称。
- options.txt 的音量、视距、全屏独立保存；保留其他行、含冒号的值和 CRLF。保存验证文件 SHA-1 修订号，防止旧界面覆盖新配置。
- 持有宿主任务锁及世界 session.lock，拒绝本启动器运行任务期间和外部占用世界时写入。备份原始配置并逐字节校验后使用现有原子文件写入。
- 头像显示皮肤正面与帽子层。正版皮肤只从官方 textures.minecraft.net 下载，拒绝跨来源重定向；离线头像按离线 UUID 保存。头像请求返回时校验当前身份，避免切换账户后显示旧头像。

## 验证

- 前端生产构建、类型检查、ESLint、Prettier 检查。
- Vitest：30 项；Edge：8 项，包括规则表单保存、跨账户旧头像响应丢弃、默认真实库空态、最小窗口、主题、账户入口和旧演示回归。
- Rust：26 项通过、4 项公网集成测试默认忽略；Clippy 与 rustfmt 检查。
- 新增 Rust 测试：单字段修改时其余原始 NBT 字节完全一致；规则变长、天气、时间和默认模式往返；未知标签/世界总年龄保持；备份逐字节一致；过期修订、占用锁、极限模式、非法规则和路径拒绝；选项 CRLF/未知行保留与非有限数值拒绝。
- 真实 Tauri/WebView2 检查：Java 21、官方清单、Fabric 清单、账户切换、离线 PNG 头像、28 项规则测试存档、难度/时间/天气修改回读、备份一致、音画选项保存、内存配置及窗口行为。仅操作项目 .native/integration 测试目录。
- Release 从新首页实际启动 Minecraft 1.21.1 + Fabric 0.16.14，到 OpenAL 初始化并结束进程；运行时绕过 UI 直接调用保存命令也被原生层拒绝。公网 Fabric 清单曾超时；使用 `node scripts/smoke-native.mjs release --cached --launch-offline --fabric` 跳过联网清单查询，本地资源完整流程连续两次通过。首次发布版存档选择出现过一次读取超时，随后未复现；测试脚本已补充失败截图与诊断输出，尚无可重复的配置写入故障。

## 使用与恢复

选择实例 → 存档与设置 → 退出此实例的游戏 → 重新读取配置 → 调整 → 勾选已关闭游戏 → 保存。世界设置与音画选项分别保存。

保存消息显示备份的完整路径。需要恢复时先完全退出游戏与启动器，将该备份复制回对应世界的 level.dat 或实例的 options.txt；保留当前文件副本。备份目录只含本次修改前的配置文件，不含区块，不替代完整世界备份。

## 尚未验证或不支持

- 世界文件集成测试使用合成 NBT 元数据夹具，并非完整可游玩存档；尚未在游戏里加载修改后的世界进行人工验收。不修改用户已有世界。
- 极限模式只读；26.1 的新布局拒绝编辑。新布局依据 [Minecraft Java Edition 26.1 官方发行说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-1) 的难度结构变更，需独立适配。
- 无法可靠识别外部启动器游戏停在主菜单的情况，所以保存前要求退出该实例。操作系统权限、磁盘或并发外部写入仍可能使保存失败，失败会显示错误。
- 正版账号的实际授权与头像端到端流程未由本人账户验收。离线头像不负责让其他玩家或游戏内看到自定义皮肤。
- 没有实现整合包自动安装、任意 NBT 编辑、区块/背包编辑、已有玩家模式迁移或 Forge/NeoForge。系统级内存整理仍默认关闭，本轮未对用户其他应用执行整理。
