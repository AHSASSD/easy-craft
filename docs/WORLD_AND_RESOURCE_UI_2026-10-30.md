# 存档直接编辑与资源详情间距

- 移除存档／音画设置的“我已关闭游戏”人工勾选和相关状态。保存直接可用，保留已知游戏及任务运行锁定、本地服务可用性检查、未保存修改保护、后端 session.lock、旧版本校验和保存前自动备份。
- 配置恢复和旧备份管理同步去掉人工关闭游戏依赖；具体变更确认、清理确认及未保存编辑拦截继续工作。未取消恢复与清理自身的确认，也未改变世界文件写入逻辑。
- 资源详情返回栏增加 16px 水平内边距，与卡片内容对齐，保留 sticky 固定。项目介绍使用独立样式和 24px 下方间距，不再贴着版本与下载标题；展开介绍后仍有分隔。

验证：类型检查、ESLint、96 项前端测试、14 项既有 E2E 和桌面 debug 构建通过。相关测试覆盖直接保存、自动备份结果、运行中禁用、未保存修改阻止恢复，以及清理确认。

`node scripts/verify-world-resource-ui.mjs` 使用隔离目录中的合成有效 NBT 存档，实际通过 Tauri UI 修改难度并保存，重新读取验证新值，核对自动备份 SHA-1 等于原始 level.dat。测试不涉及个人存档、账号或游戏启动。

真实在线打开 Fresh Animations 资源详情，验证返回按钮相对卡片左侧内缩 16px，项目介绍与版本目录间距至少 24px；介绍展开、收起、滚动到底部及返回搜索均正常。检查浅色、深色及 1120×720、900×600 逻辑窗口。截图和记录在 `output/playwright/world-resource-ui/1135cf5b-effa-4053-8b1a-630685e5e3cf/`（深色）与 `output/playwright/world-resource-ui/3abcbea9-c28d-45d5-9318-bb5eea67f738/`（浅色）。

产物：`src-tauri/target/debug/easy-craft.exe`。外部游戏状态仍以实际文件锁等证据为准，没有引入全进程识别承诺。
